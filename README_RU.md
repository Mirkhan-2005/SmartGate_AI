# SmartGate AI — улучшенная локальная версия

Новый интерфейс для Windows, FaceNet, OpenCV, SQLite. Оригинальный `face-detect.py` не нужен для запуска этой версии.

## Возможности

- **Загрузить фото:** имя → JPG/PNG → автоматическое обнаружение одного лица и создание FaceNet-эмбеддинга.
- **Сделать фото:** имя → включить камеру → снимок → автоматическое сохранение.
- **Список пользователей:** фотографии и имена.
- **Удалить:** удаляет фото, эмбеддинг и связанные записи журнала (без корзины).
- **Автообновление базы:** после добавления/удаления не нужна кнопка Data.
- **Распознавание:** имя/unknown на видеопотоке, журнал событий с задержкой не менее 60 секунд между записями для одного человека.
- **Журнал:** история и экспорт CSV в UTF-8.
- **Импорт старых данных:** фотографии `fotoPeserta/*.jpg` из прежнего проекта можно импортировать кнопкой «Импорт старых фото».

## Установка Windows 11

Необходимы Python **3.11 x64**, работающая камера и интернет при первой загрузке весов FaceNet.

1. Распакуйте архив в `D:\Project\Smart-Gate-AI-Face-Recognition-Attendance-System` **или отдельную папку**. При совмещении со старым репозиторием не удаляйте `face-detect.py`.
2. Откройте терминал CMD в папке с файлом `smartgate_app.py`.
3. Выполните:

```cmd
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python smartgate_app.py
```

**Более простой вариант:** запусти двойным щелчком `START_WINDOWS.bat` — скрипт сам создаст `.venv` (если нет), установит зависимости и откроет программу. Для этого Python 3.11 должен быть уже установлен на Windows.

Для обновления зависимостей после изменения `requirements.txt` удали только файл `.venv/.setup_complete` и вновь запусти `.bat`.

Папки `data/` и `data/faces/`, SQLite база `data/smartgate.db` будут созданы **автоматически**.

## Быстрая проверка

1. Дождитесь надписи «FaceNet готов» справа сверху.
2. «Пользователи» → имя → «Загрузить фотографию» (JPG/PNG с **одним лицом**) → сообщение об успешном добавлении.
3. Или «Пользователи» → имя → «Включить камеру» → «Сделать снимок и сохранить».
4. Перейдите в «Распознавание» → выберите индекс камеры `0`/`1`/`2` → «Начать распознавание».
5. Дождитесь появления имени или `UNKNOWN`. Откройте «Журнал» для проверки событий и экспорта CSV.
6. «Пользователи» → «Удалить» удаляет локальные данные выбранного человека.

## Миграция со старого проекта

Скопируйте `smartgate_app.py`, папку `smartgate/`, `requirements.txt` в корневую папку старого репозитория. Оригинальный `face-detect.py` остаётся нетронутым. Старые фото `fotoPeserta/Имя.jpg` НЕ переносятся автоматически; нажмите «Импорт старых фото», и каждое пригодное изображение будет обработано FaceNet.

Старая база `database.pkl` не импортируется: это отдельный формат. Новая база SQLite формируется по фотографиям без повторного обучения нейросети.

## Если не работает камера

- В разделе распознавания попробуйте индексы 0, 1, 2.
- Закройте Zoom, Teams и другие приложения, использующие камеру.
- Windows → Параметры → Конфиденциальность и безопасность → Камера → разрешите доступ.
- Выполните тест:

```cmd
python -c "import cv2; c=cv2.VideoCapture(0,cv2.CAP_DSHOW); print(c.isOpened()); ok,frame=c.read(); print(ok); c.release()"
```

## Известные ограничения

- **Демонстрационный прототип.** Нет аппаратного управления турникетом, проверки прав доступа, защиты от фото/видео (liveness), аутентификации администратора и безопасного резервирования.
- Биометрические шаблоны и фото **хранятся локально без шифрования**. Не используйте реальные данные других людей без их осознанного согласия. Не выкладывайте `data/` в GitHub.
- Совпадение при расстоянии FaceNet ≤ 1.0 является эвристикой, не гарантией правильной идентификации. Проверьте точность на тестовой выборке, прежде чем интегрировать турникет.
- Журнал означает **распознавание**, не реальное открытие двери или факт прохода.
- TensorFlow и FaceNet могут стартовать долго при первом запуске, так как модель загружается и могут скачиваться веса.
- Приложение на CPU может делать распознавание не в каждом кадре, чтобы интерфейс оставался отзывчивым.
- При удалении пользователя безвозвратно удаляются его фото, шаблон и связанные события журнала; скопированные исходные фото вне `data/` остаются.
